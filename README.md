# Selenium Web Form Tests

Учебный проект по автоматизации UI-тестирования веб-формы с использованием Java, Selenium WebDriver и JUnit 5.

## Технологии

- Java
- Selenium WebDriver
- JUnit 5
- Maven

## Покрытые сценарии

- Ввод текста в текстовое поле
- Ввод текста в многострочное поле
- Проверка недоступного поля (disabled)
- Проверка поля только для чтения (readonly)
- Выбор значения в выпадающем списке
- Проверка чекбокса
- Проверка ползунка

Тесты проверяют поведение элементов формы с помощью Selenium WebDriver и утверждений JUnit 5.
